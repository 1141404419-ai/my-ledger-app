# 我的账本

一个移动端优先、只在本机保存数据的单页记账应用。

## 功能

- 快速记录收入和支出
- 按月份查看账单、结余和分类占比
- 编辑账单、删除撤销
- 近 6 个月收支趋势
- JSON 备份恢复和 CSV 导出
- 可安装到 Android 桌面，并支持离线打开

## 数据说明

账目保存在当前浏览器的 `localStorage` 中，不会上传到 GitHub 或任何服务器。清理浏览器数据或更换设备前，请在应用设置中导出 JSON 备份。

## 使用

直接打开 `index.html` 即可使用。部署到 HTTPS 静态网站后，可在 Android Chrome 中打开页面并通过“安装应用”或“添加到主屏幕”作为独立 App 使用。
